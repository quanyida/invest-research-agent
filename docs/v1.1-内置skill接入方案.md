# v1.1 内置 Skill 接入方案

日期：2026-11-17
范围：只做内置工具层，不做用户自定义工具

## 1. 目标

让 Agent Loop 能正确使用 iFinD 官方 Skill 描述的取数能力，优先解决三类问题：

1. 问港美股（如「深度分析下谷歌」）时，错误调用 A 股接口
2. 工具选择与问题语义不匹配
3. 非人民币金额、PE 单位、多期期间解析错误

验收用例：

> 深度分析下谷歌的业务情况和 AI 时代下的预期

要求：status=done，evidence 来自 global server，金额单位为亿美元，PE 单位为倍，答案带 [E1-x] 引用。

## 2. 为什么不能直接跑 Skill

Skill 是给「能读文件、能执行命令」的 Agent 设计的（SKILL.md + references + call.py）。
本项目 loop 是封闭工具集：router 规则 -> registry 白名单 -> gateway.call()，不读文件、不执行脚本。

因此采用「编译期接入」：把 Skill 的 references 解析成结构化 catalog，运行时只读 JSON。

## 3. 分层设计

- 内置层（本期）：代码定义，随版本发布
- 租户启用层（预留）：同一实现，按租户开关/配额/凭证
- 用户自定义层（不做）：用户注册 MCP/HTTP 工具

本期只落地内置层，但接口按三层预留：

    build_tool_catalog(tenant_id, user_id, domain) -> list[ToolSpec]

## 4. 数据流

    question
      -> detect_domain()        规则定域，0 延迟
      -> route_question()       命中则直接出 Plan，不调模型
      -> _llm_plan()            未命中时，只喂当前域的工具 + skill 示例
      -> gateway.call()         统一走 iFinD JSON-RPC
      -> parser                 产出 fact（带币种/期间/单位）
      -> verify                 数字必须能对上 fact

## 5. 改动清单

### P0 阻塞修复

- app/agent/loop.py:297 规划超时 8s -> 20s（实测模型回 OK 需 10.5s）
- app/agent/router.py:61 实体抽取剥离动词前缀，拒绝「深度分析下谷歌」这类候选
- app/agent/loop.py:339 fallback 不再对未知实体硬套 A 股 stock_summary

### 内置 Skill Catalog

- scripts/build_skill_catalog.py：解析 skills/ifind-finance-data/references/*.md
- 产物 app/tools/skill_catalog.json：domain -> tools[{name, desc, example}]
- app/tools/skill_catalog.py：运行时只读 JSON，提供示例查询

### 港美股能力

- ifind_gateway.py SERVER_PATHS 增加 global
- registry.py 增加 5 个工具：global_profile / global_quotes / global_financials / global_events / global_screen
- rewrite.py 对 global 工具直接透传 query，不做结构化拼接
- router.py 增加 GLOBAL_ALIASES 与 detect_domain()

### 解析与校验

- parser.py：币种透传（美元/港元）、PE 单位修正、多期 period_end 取最新、报告期标签
- verify.py：数字正则与单位换算支持亿美元/亿港元
- context.py：金额规则由「统一亿元」改为「保留原始币种」

## 6. 明确不做

- 用户自定义工具注册与执行
- 基金/债券/期货/企业/法律五类域上线（catalog 保留，registry 不注册）
- Skill 脚本运行时（call.py / call-node.js）
- 评测集与压测

## 7. 验证方式

1. 单元级：parser 对 global 原始返回产出 亿美元/倍/正确期间
2. 路由级：extract_entities 与原问题 -> 命中 global，0 次 LLM 调用
3. 端到端：网页提问原验收用例，检查 status/evidence/tool/unit
4. 回归：A 股典型问题（贵州茅台毛利率）仍走 stock
