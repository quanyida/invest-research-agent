# v1.11 答案结构重构与 web.search 强制预检索

## 1. 为什么改

旧四段是“结论 / 关键数字 / 正文 / 边界”，实际使用有三个问题：

1. 判断散落在“正文”里，多条件筛选问题无法逐条对应条件；
2. “边界”被写成固定两行“口径与缺失 / 分歧”，模型经常为了凑格式写空话；
3. web.search 依赖模型自主决定，模型经常直接走 iFinD，公开信息没有稳定进入上下文。

v1.11 把答案改成“先结论、再逐条依据、再关键数据、最后缺口”，并在每轮 Agent 推理前由程序强制执行一次 web.search。

## 2. 新答案契约

统一四段纯文本：

```text
结论：先直接回答；是非题先写“符合/部分符合/不符合/无法判断”。
依据：用编号逐条列出支撑事实或推理，每条只承担一个判断，事实后紧跟 [E轮次-序号]。
关键数据：主体、期间、指标、数值、单位、引用；无数字写“本轮无关键数字。”。
待确认：未取到的数据、未验证标准、口径差异、来源分歧；无缺口写“本轮未发现明显缺口。”。
```

约束：

- 不使用 Markdown、代码块、过程说明；
- 任务型问题（公司研究/行业研究/业绩点评）仍在“依据”内使用固定小标题；
- 多条件筛选问题在“依据”中逐条写“满足 / 不满足 / 无法验证”；
- “待确认”只写数据缺口和口径分歧，不写校验错误或过程说明。

代码位置：

- `app/agent/answer_format.py`：`SECTION_LABELS`、`SECTION_PATTERNS`、`FORMAT_CONTRACT`、`SECTION_RULES`、`answer_is_complete()`；
- `app/agent/context.py`：system prompt 与兜底文案；
- `app/agent/agentscope_runtime.py`：最终答案、修订轮、合成轮；
- `app/agent/answer_guard.py`：修订指令；
- `app/agent/persist.py`：中断兜底；
- `app/agent/loop.py`：缺段补齐；
- `app/agent/verify.py`：同时兼容新四段与旧四段。

## 3. web.search 强制预检索

### 3.1 流程

每轮对话在创建 AgentScope Agent 之前：

1. 检查 `WEB_SEARCH_ENABLED`、API Key 和 `web.search` 是否在允许工具中；
2. 用用户问题生成确定性 query（去掉“帮我/深度分析下”等前缀，截断到 200 字）；
3. 直接调用 `web.search`，默认 `count=6`、`freshness=oneMonth`；
4. 成功结果写入本轮证据和 system prompt 的“本轮自动预检索”块；
5. 通过 SSE 发出 `tool_start / evidence / tool_end`，前端能看到这次搜索；
6. 失败只记录 `WEB_PREFETCH_FAILED`，不阻断主流程。

### 3.2 预算与审计

- 预检索不扣 `max_tool_calls`，避免挤占 Agent 自主调用 iFinD 的预算；
- 但会计入证据、审计、token 统计和最终 `meta.web_prefetch`；
- 模型仍可在预检索不足时补充调用 `web.search`，但禁止用完全相同的 query 重复调用。

### 3.3 代码位置

- `app/agent/prefetch.py`：`build_prefetch_query()`、`prefetch_web()`；
- `app/agent/run_context.py`：`prefetch_block`、`prefetch_info`；
- `app/agent/event_bridge.py`：`record_events()` 把预检索转换成既有 SSE 事件；
- `app/agent/agentscope_runtime.py`：在 `Agent(...)` 之前执行预检索。

## 4. 前端

- 四段标签改为“结论 / 依据 / 关键数据 / 待确认”；
- “依据”按编号逐条渲染，不再合并成一大段；
- “关键数据”逐行等宽显示；
- “待确认”弱化颜色；
- 来源卡片同时支持 fact 级和 evidence 级引用：web 证据没有 fact 时，用证据的 `query_text` 和 `as_of_label` 展示，点击可定位到右侧证据卡；
- 历史消息仍兼容旧四段“结论 / 关键数字 / 正文 / 边界”。

## 6. 迁移影响

| 区域 | 变化 |
|---|---|
| prompt | 四段标签、依据编号、待确认口径 |
| 兜底文案 | 无证据、超时、中断均改为新四段 |
| 修订轮 | 修订指令改为新四段 |
| verify | 新四段为主，旧四段仅兼容 |
| 前端 | 新四段渲染、列表行、evidence 级来源卡片 |
| 测试 | 旧契约断言改为新契约，新增长格式校验用例 |
