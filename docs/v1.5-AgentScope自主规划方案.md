# v1.5 AgentScope 自主规划方案

日期：2026-11-18

状态：已实施

## 1. 决策

AgentScope 链路不再做“前置规划”：

- 不再按问题调用 `route_question()` 生成 `Plan`
- 不再按问题裁剪 `domain` 和工具白名单
- 不再在进入 ReAct 前判断 `global` / `stock` / `macro` / `news`
- AgentScope 每轮拿到当前租户可用的完整工具目录，自行判断市场、标的、指标和调用顺序

保留的是非规划类安全边界：

- 登录、租户隔离、RLS、限流、日配额
- 工具只读权限和执行前授权
- 工具预算、模型预算、超时
- 工具调用审计、evidence、fact_id
- 答案事实校验、引用修复、失败降级

## 2. 新链路

```text
POST /api/v1/chat
  -> 鉴权 / 配额 / RLS
  -> AgentScopeRunner.stream(run)
       |- RunContext：完整工具目录，不做问题路由
       |- Agent(model, toolkit, state, react_config)
       `- reply_stream(UserMsg(question))
            |- Agent 自主判断：市场、标的、时间、指标
            |- Agent 自主选择工具并执行
            |- EvidenceCollector 记录 evidence / audit / fact_id
            `- Agent 输出最终答案
       |- AnswerGuard：引用修复 -> 事实校验
       |- 不通过则同一 AgentState 修订一轮
       `- 仍不通过则 evidence digest 降级
  -> SSE: meta/plan/tool_start/tool_end/evidence/verify/delta/usage/done
```

## 3. 工具面

`resolve_agentscope_tools()` 返回当前工具注册表中的完整工具目录：

- A 股：`stock_*`、`screen`
- 港美股：`global_*`
- 新闻公告：`news_search`、`notice_search`
- 宏观指数：`macro`、`index`

工具层仍保留 `check_permissions()`，即使模型选择错误，也只能执行注册且授权过的工具。

当前不区分租户套餐，全部租户看到同一套工具。后续如果增加 free/pro 套餐，应在 `resolve_agentscope_tools()` 做静态授权过滤，而不是恢复按问题路由。

## 4. 提示词

系统提示词新增静态“工具选择”规则，只描述能力边界和选择原则，不解析具体问题：

- 美股、港股、海外标的优先 `global_*`
- A 股优先 `stock_*` / `screen`
- 新闻公告、宏观、指数按工具描述选择
- 不确定市场时先用 profile / summary / news 验证
- 上传、PDF 全文、网页抓取、涨跌原因解释没有对应工具，直接说明边界

这些规则不构成前置计划，AgentScope 仍可在 ReAct 中根据 observation 改变下一步。

## 5. SSE 语义

`plan` 事件保留，兼容前端和下游 Agent，但语义改为“工具面公告”：

```json
{
  "mode": "agentscope_auto",
  "intent": "agentscope_auto",
  "tools": [],
  "allowed": ["ifind.stock_quote", "..."],
  "domain": "auto",
  "entities": []
}
```

前端在 `mode=agentscope_auto` 时显示“Agent 自主选择工具 · 可用 N 个”，不再显示预设工具列表。

## 6. legacy 回滚

`AGENT_ENGINE=legacy` 时仍走原 `AgentLoop`，继续使用 `router.py` 和 `resolve_allowed_tools()`。本次不改 legacy，避免回滚链路失效。

## 7. 验收

单元测试：

- `tests/test_run_context_auto.py`
- `tests/test_router_global.py`
- `tests/test_evidence_ids.py`
- `tests/test_parser_units.py`
- `tests/test_verify.py`

真实请求：

- 美股 SMTC：AgentScope 自主选择 `global_*` + `news_*`，`verify.passed=true`，`status=done`
- A 股贵州茅台：AgentScope 自主选择 `stock_financials`，`verify.passed=true`，`status=done`
- PDF 全文请求：无对应工具，不调用工具，返回能力边界/无证据降级

## 8. 风险

- 工具目录从 10 个左右扩大到 17 个，系统提示词和工具 schema 的 token 开销增加。
- 模型可能选错市场工具；通过工具描述、静态选择规则和校验/降级兜底。
- 原先由前置规划直接拦截的能力问题，现在依赖提示词和工具缺失；建议后续观察 PDF、全文、因果类问题的回答质量。
